BaoCode Claude 1.9.7

A feature release: themes that follow the system, project ordering, and
steadier sessions when a turn is stopped or its stream is cut.

New
- The theme can be set to Auto, following the system's light or dark
  appearance; switching is smooth rather than a hard repaint.
- Projects in the sidebar are ordered by recent activity, or in the order
  you arrange them.
- A stopped turn's work folds like a turn read back from the session file,
  so a long conversation stays compact.

Improved
- Upstream addresses are shown in full, and Magpie's gateway is followed
  as an upstream: its models are taken again on start, every ten minutes
  and as its page opens.
- Update checks keep a high-water version: a manifest older than the one
  already run or installed is a replay, not a downgrade, while the same
  version published again with a new file is still offered.

Fixed
- A stopped turn no longer takes the next one with it: a result come late
  for it, or a stale `started` message, does not end the turn sent since.
- A proxy's authentication challenge is not mistaken for Claude Code being
  logged out, so a dropped process is retried as it should be.
- What Claude Code abandons in a cut stream goes, instead of staying in the
  conversation.
- A tool call on Windows names the file, not its whole path.
- A table's text selects like the text around it.
- A removed SSH host is not connected to at startup.
- The numpad's 1 and 7 type digits with NumLock on.
- The browser extension joins the Windows discovery folder with Windows'
  separator, so it finds the app reliably.

This update carries the current Claude Code.
