BaoCode Claude 1.10.0

一次较大的上游同步：工作台的分屏与标签页、跟随系统的主题、浏览器控制、
手机连接与用量成本，以及更稳定的 Claude Code 会话。

新功能
- 分屏：多个 Agent 并排，各自有标签页和侧栏；一个窗格的层叠作为标签页，
  可拖到另一个旁边或交换位置，布局会被记住。
- 工作台的终端同时出现在对话面板和侧栏，各有圆角标签；每一列或每一行都能独立调整大小。
- 主题可跟随系统（自动）并平滑切换；浏览器扩展可访问本地文件，Agent 能在页面里拖拽、
  使用笔压和按住修饰键。
- SSH 远程主机支持 Linux RISC-V；Magpie 网关作为上游被跟随；模型可按层级、时段和服务费定价，
  用量页展示成本。
- 手机端：通过连接查看 bots 和 Agent 标题，对话旁用 `/btw` 追问，从手机发送消息和图片，
  下载码在 设置 → 移动端。
- 从 JSON 导入 ChatGPT 凭证；输入框里的 `/fork` 会分叉对话并打开副本。

改进
- 流式回复每帧最多重建一次视图，窗口在后台时更少；正在写入的代码块只布局和着色变化的部分；
  提交面板和大段插入的重建更省。

修复
- 正确读取 Claude Code 最终的缓存用量，保留输入为 0 的占位。
- 文件链接可跨越 shell 的 cd 和机器打开；路径按项目根目录的写法解析，POSIX 项目的文件在
  Windows 上保持斜杠。
- 停止一个回合后，下一条消息不会再被它迟到的结果打断；代理要求认证时不再误判为未登录。
- Claude Code 在截断的流里放弃的内容会移除；无法读取的规则文件会跳过，不会让整个记忆失败。
- OpenCode 不再收到会话头或空工具列表；上游拒绝 cache_control 时会去掉它重试。
- 窗格的标签页在重启后保留，队列消息可拖动排序，命令默认由用户运行而不是模型。

本次更新携带当前版本的 Claude Code。
