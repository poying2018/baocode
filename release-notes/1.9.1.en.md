BaoCode Claude 1.9.1

A fix release: when a model or its provider answers with nothing, the
conversation now says why instead of ending in silence.

Fixed
- A message whose model answered with no visible content -- a provider that
  refused the request, or an empty reply -- now ends with an error that says
  what happened, using the provider's own last error when it left one.
- The retry the CLI sends itself after such an answer no longer appears as
  a message you sent.
- An upstream's API error shows as an error in the conversation, and the
  same error is not repeated twice.
- Stopping a turn yourself no longer adds an error for it afterwards.
