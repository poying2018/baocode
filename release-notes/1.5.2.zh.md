Markdown，就地编辑

stash、Markdown 文件的预览和对话里的输入框，现在共用一个 Markdown 编辑器：正文按
Markdown 显示，光标所在的段落用它自己的标记，写在哪里就在哪里改，不必另开一个框。

新功能
- stash、Markdown 文件预览和对话输入框共用一个 Markdown 编辑器：正文按 Markdown 显示，格式工具栏跟着光标，只给出那一处用得上的标记。
- Markdown 文件的预览可以就地编辑：光标处的内容随输入改变，没有单独的编辑窗口。
- stash 在预览里也有自己的格式工具栏，代码里也有：那里只给校对用的标记。
- 格式工具栏跟着选区滚动，选区不在视野里时就收起。整段文字的一次排版算一次撤销。
- 表格在自己的单元格里编辑：行和列各有自己的把手与菜单，工具栏可以添加行列，单元格的文字按下第一次就选中，拖过一片单元格像在表格软件里一样选中（复制、剪切、清空、粘贴）。表格的轮廓沿着行走，转角是圆的，表格宽时鼠标停在上面还有滚动条。
- 链接按点击时的样子显示，上方浮出气泡，可以打开、复制、编辑或删除；按住命令键打开的链接，视图停在它去的地方。右键菜单里有剪贴板的、撤销的、链接的和选区的标记。
- 行内代码的底色画在选区下面，清空的一行仍占着高度，光标与它所在行一样高。

改进
- 对话输入框的编辑器画得更快：光标后面的文字没变的地方不再重画。
- 跨行选区在周围文字被改动后仍保留它的标记。
