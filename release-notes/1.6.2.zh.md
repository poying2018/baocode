# 1.6.2

修复
- 托盘图标时有时无：图标加上了，系统却说没加上，应用就以为自己没有图标。窗口关掉后它藏到托盘，可那个图标是死的 —— 点它窗口不会回来，用户只看到应用"消失"了。现在图标确实在托盘里，点它窗口就回来；万一托盘一时不肯收下它，它会每隔几秒再试一次，直到成功。
- 托盘图标真的加不上时，窗口不会被藏起来：没有图标可点，藏起来的窗口等于应用没了。

变化
- 托盘在通知区里，不在任务栏上（Windows 11 把它收进了「隐藏的图标」的话，点任务栏右边的 `^` 能看到）。
- 托盘做了什么写在数据目录的 `logs\tray.log` 里：托盘图标找不到时，这个文件说得清它怎么了。
- 应用在 macOS 上不再构建、不再发布（这个 fork 只做 Windows 版）；远程服务端在 macOS 上仍有，那是装在 SSH 主机上的。

本 fork 与上游不同的地方
- 应用里给出的所有地址都指向这个仓库（仓库、发行版、问题、官网），见 设置 → 关于。
- 不报告使用统计，也不上传日志：没有自己的服务器，所以没有地方可去。
- 诊断在无服务器时明确说"没有服务器"，而不是静默失败。
- 渠道版的激活页仍指向上游（没有替代）。
- 推广位（ymeng / ifruit）已全部移除：列表是空的，那些图片也不再随站点发布。
- notanthropic.com 不会收到 Anthropic 的密钥。
- stash 的路径不能逃出自己的目录。
- 超大的版本号不会让应用崩溃。
