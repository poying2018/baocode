BaoCode Claude 1.9.7

功能版本：主题可跟随系统自动切换，项目可按最近活动或手动排序；
停止回合或流被截断时，会话也更稳定。

新功能
- 主题新增「自动」，跟随系统的浅色/深色外观；切换时平滑过渡，不再生硬重绘。
- 侧栏项目可按最近活动排序，也可手动调整顺序。
- 已停止回合的工作内容也会折叠，与重新打开会话时的显示一致，长会话更紧凑。

改进
- 上游地址完整显示；Magpie 作为上游被跟随：启动时、每十分钟以及打开它的
  页面时，都会重新获取它的模型。
- 更新检查记住已见过的最高版本：比它旧的清单视为重放，不会让已安装版本回退；
  同一版本重新发布并附上新文件时，仍会提示更新。

修复
- 停止一个回合后，下一条消息不会再被它迟到的结果或过期的 `started` 消息打断。
- 代理要求认证时，不会再误判为 Claude Code 未登录；进程意外退出会按预期自动恢复。
- Claude Code 在截断的流里放弃的内容会从会话中移除，不会残留。
- Windows 上工具调用只显示文件名，不再显示整条路径。
- 表格文本的选择行为与周围文本一致。
- 已删除的 SSH 主机在启动时不会再被连接。
- 数字小键盘的 1 和 7 在 NumLock 开启时能正常输入数字。
- 浏览器扩展用 Windows 的分隔符拼接发现目录，能可靠找到应用。

本次更新携带当前版本的 Claude Code。
