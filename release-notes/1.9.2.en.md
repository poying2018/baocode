BaoCode Claude 1.9.2

A fix release: when an upstream fails, the conversation says so.

Fixed
- An upstream that answers a streaming request with JSON -- some gateways
  send their refusal with HTTP 200 -- now shows as a failed request with
  its message, instead of an empty answer that ends the turn in silence.
- A subagent's upstream error no longer keeps the turn's own error from
  being shown.
