BaoCode Claude 1.9.6

修复版本：浏览器扩展连接、MCP 会话、队列消息和中文搜索的一批问题，
Windows 上的退出与系统代理读取也更可靠。

改进
- Windows 上的系统代理改为在进程内读取，不再启动 `reg.exe`，打开网络相关页面更快。
- 流式回复每帧只重建一次对话；窗口在后台时，刷新频率也会降低。

修复
- 浏览器扩展现在通过应用的本地数据目录找到 BaoCode，不再依赖 `TEMP` / `TMP`；
  Chrome、Edge 等 Chromium 浏览器里的扩展在 Windows 上连接更可靠。
- 连接严格检查请求长度的 MCP 服务器时，「测试连接」和真实会话都能正常完成；
  结束会话或退出应用时，未完成的 MCP 登录和挂住的后台任务会一并清理。
- 在 Claude Code 进程启动期间或后台任务运行期间，队列里的「立即发送」都不会丢失消息。
- 中文整词搜索在对话、编辑器、终端和文件搜索里保持一致：`订单` 能在
  `查看订单列表` 中找到，`order` 不会匹配 `订单order列表` 里的一截。
- 同名模型会带上上游标签；子 Agent 使用会话所属上游的模型，强制指定
  子 Agent 模型时不再显示无法生效的模型选项。
- 上游把用量数字写成字符串时，Claude Code 会话不会再因此读取失败。
- Windows：退出应用不再崩溃；托盘菜单里的「退出」在确认框弹出时也能用。
- 聊天里的 Windows 路径、`/C:/` 链接和带引号的程序路径都能打开正确的文件或程序；
  窄窗口下，已结束回合的文本会正常换行。
- 状态栏会统计选区覆盖的行数；从侧栏可以用系统默认程序打开未显示的文件。
- 「发布说明」打开正确的 `v1.9.6` 页面。

本次更新携带当前版本的 Claude Code。
