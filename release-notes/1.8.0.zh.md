BaoCode Claude 1.8.0

这一版把 IDE 的整套 Git 能力搬了进来：能只提交改动的一部分，能在日志里
直接操作，行首就有 blame，冲突有三方合并，改动、提交和冲突都能交给 AI。
WSL 发行版里的工程也能在这里直接打开。

新功能
- 打开 WSL 发行版里的工程，和 SSH 主机放在一起。
- Git，按 JetBrains IDE 的做法：本地改动在提交面板里，有变更集、提交选项
  和消息历史，可以只提交文件的一部分，有 Fixup、按合并或变基更新项目、
  交互式变基、远端分支、Push，还有一个 Stash 页。
- 能在里面干活的 Git 日志：分支树，文件、文件夹和行的历史，可以一次选中
  多个提交，diff 按 IDE 的样子显示。
- 行首的 Git Blame，以及 agent 改过的行在行首标出来。
- 提交前让 AI 审一遍；对一处改动、一个提交或一个冲突问 AI；冲突可以由
  AI 来合。
- 保存过的文件有本地历史，能看到一个文件过去的样子。
- 可以自己加语言服务器（打开 Open Language Server Settings）。
- 编辑器里的长行自动折行，一个设置管全部。
- 全屏，在「视图」菜单里，也可以按 F11。
- 项目可以全部折叠、全部展开；置顶的项目留在最上面；把指针停在会话上
  会显示它用的模型。
- 可以改项目的名字和位置，它的会话会一起搬过去。
- 从起始页克隆仓库；管理远端和标签。

修复
- 检查更新时，有版本可能被认成「已经是最新」而其实不是。现在能正常收到。
- 写过又清空的 stash 是一个 stash，不再是面板会接着用的那个草稿。
- 供应商的模型能通过用户设置的 availableModels，批量测试里也一样。
- 子代理在项目外的改动，以及通过链接打开的项目，都能被正常审查。
- 输入法在选区上组合的文字，会替换掉选区。
- 代码块在它的闭合围栏处结束。
- 打开超过 256 个文件时，之后启动的进程不会再卡住。
- 「实时输出」按滚轮的方向滚动，到底就停住。
- 更新会替换掉浏览器重新拉起的那个宿主程序。
