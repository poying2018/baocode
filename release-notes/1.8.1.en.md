BaoCode Claude 1.8.1

A fix release. Chinese typing in the chat input works as it should: what
an input method composes is left alone, so the characters you pick are
the ones that go in.

Fixed
- Typing Chinese in the chat input left the pinyin behind: the text an
  input method was composing was taken for the text itself, so the pinyin
  went in as it was — apostrophes and all — and the next word was
  composed beside it rather than over it. The input method is now left
  alone while it composes, and the characters you pick go in where the
  caret is.
- Two places named the program BaoCode where they now name it as this
  program is called.
