地址都指向本仓库，Windows 上打字回来了

这一次把上游 1.5.2 之后的 27 个提交并进来（Windows 输入、Skia 渲染、侧栏交通灯、
长会话的性能等），并把应用里所有对外的地址改成这个仓库自己的 —— 关于页的仓库、
发布页与问题反馈，星标提示框里的仓库，提交署名里的邮箱，站点自己的文件（渠道
列表、推荐上游），以及下载链接的许可名单。

用到上游服务的两处不再用：使用统计不再上报（日志也不再上传），因为这个版本
没有自己的服务器；渠道版的激活页仍指向上游，因为没有替代。

新功能
- 侧栏的预览可以直接拖入文件，右键能显示一个。
- 输入框里的 /命令 会显示它的完整说明，说明所在的文件能打开。
- 改动过的文件的菜单里，可以当作文件打开：在浏览器里、用系统默认程序、或在编辑器里。
- 智能体工作时，在空的输入框里按回车，就把排队的消息发出去。
- 上游或模型可以一键复制一份。
- 默认用 Claude Code CLI 作内核；内置内核会建议改用它。

改进
- 长会话的文本里，路径按位置查，不再每次从头找；卡住的报告读得懂了。
- 编辑器共用一套分词器，Skia 与图片缓存保持得小，内存回收得更早。
- 输入框里光标后的文字没变的地方不再重画。
- 侧栏的边缘跟着指针走；触控板在编辑器里滑动像列表一样，到头不再回弹。

修复
- Windows 上 stash 与对话输入框又能打字了。
- 窗口左上角，侧栏的开关和标签不再被交通灯挡住。
- 重新打开一个对话，还停在上次的地方。
- 输入框里的 @ 也能按名字找到文件夹。
- Windows 上改用 Skia 绘制，与 macOS 一致，不再用 Impeller。
- 在 Claude Code 里用 /rename 改过的对话名，在列表里也是新的。
- 计划模式下缓存先于提醒结束，下一轮读得对。
- 快速提问的答案从详细输出的数组里读，不再从 stderr 里猜。
- 断掉的 SSH 连接会接回同一个会话，之前的东西没有丢失或结束。
- 一个只以 anthropic.com 结尾的域名（notanthropic.com）是别人的，不发我们的 key。
- stash 里的文件名只是名字，不带路径，`..` 也走不出文件夹。
- 太大的版本号是无效的版本，不是崩溃。
- 失败的工具调用，在给模型看的文字里说明了。
