# 1.6.1

这个 fork 从此只做 Windows 版：macOS 的应用不再构建、不再发布。已有的 Windows 用户不受影响，照常自动更新。

变化
- macOS 的应用不再构建，也不再发布。下载页和首页去掉了 macOS 的部分，指向它的链接也去掉了（那些链接会指向一个不存在的文件）。
- 发布工具不再接受 macOS 与 dmg 的选项，写出来的更新清单里不会有 macOS 的条目。
- macOS 远程服务端仍然提供（那是装在 SSH 主机上的服务端，与桌面应用无关）。
- 应用代码里 macOS 的分支留着：应用在 Mac 上跑时会走到那里，只是不再从这边发布。

本 fork 与上游不同的地方
- 应用里给出的所有地址都指向这个仓库（仓库、发行版、问题、官网），见 设置 → 关于。
- 不报告使用统计，也不上传日志：没有自己的服务器，所以没有地方可去。
- 诊断在无服务器时明确说"没有服务器"，而不是静默失败。
- 渠道版的激活页仍指向上游（没有替代）。
- 推广位（ymeng / ifruit）已全部移除：列表是空的，那些图片也不再随站点发布。
- notanthropic.com 不会收到 Anthropic 的密钥。
- stash 的路径不能逃出自己的目录。
- 超大的版本号不会让应用崩溃。

修复
- 见 1.6.0 的日志；这一版没有别的修复。
