BaoCode Claude 1.9.6

A fix release: browser extension connections, MCP sessions, queued messages
and Chinese search, with steadier quitting and proxy reads on Windows.

Improved
- Windows' system proxy is read in the process instead of by starting
  `reg.exe`, so network-related pages open faster.
- A streamed reply rebuilds the conversation once a frame; refresh also
  slows down while the window is in the background.

Fixed
- The browser extension finds BaoCode through the app's local data folder
  instead of `TEMP` / `TMP`, so extensions in Chrome, Edge and other
  Chromium browsers connect reliably on Windows.
- MCP servers that strictly check the request length now pass both the
  connection test and real sessions; unfinished MCP sign-ins and tasks
  held open by their output are cleaned up when a session ends or the app
  exits.
- "Send now" on a queued message no longer drops it while Claude Code is
  starting or background tasks are running.
- Whole-word search in Chinese now agrees across chat, editor, terminal and
  file search: `订单` is found inside `查看订单列表`, and `order` does not
  match the order inside `订单order列表`.
- Models with the same name are told apart by their upstream; a subagent
  uses its session's upstream, and a forced subagent model no longer
  offers a choice that cannot take effect.
- Claude Code sessions no longer fail to load when an upstream sends usage
  numbers as strings.
- On Windows, quitting no longer crashes, and the tray's Quit works while
  the confirmation is up.
- Windows paths, `/C:/` links and quoted program paths in chat open the
  right file or program; a finished turn's text wraps in a narrow
  conversation.
- The status bar counts the lines a selection covers, and a file not shown
  in the editor opens in its default app from the side panel.
- Release Notes opens the `v1.9.6` page.

This update carries the current Claude Code.
