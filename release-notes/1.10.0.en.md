BaoCode Claude 1.10.0

A large update from the upstream: panes and tabs in the workbench, themes
that follow the system, browser control, phone links and usage costs, with
steadier Claude Code sessions.

New
- Panes: agents side by side, each with its own tabs and side panel; a pane's
  layers as tabs, dragged beside another or swapped, and the layout kept.
- The workbench's terminals live in the chat's panel and the side panel at
  once, in rounded tabs of their own; each column or row resizes on its own.
- The theme can follow the system (Auto), with smooth changes; the browser
  extension can reach local files, and agents can drag, use pen pressure and
  hold modifiers in a page.
- SSH remote hosts on Linux RISC-V; Magpie's gateway followed as an upstream;
  models priced with tiers, hours and fees, their cost across the usage pages.
- The phone app: bots and agent titles over the link, `/btw` beside a
  conversation, messages and pictures from the phone, and its download codes
  in Settings → Mobile.
- ChatGPT credentials imported from JSON; `/fork` in the input forks a
  conversation and opens the copy.

Improved
- A streamed reply rebuilds the view at most once a frame, and less often in
  the background; a code block being written lays out and colors only what
  changed; the commit panel and large inserts are cheaper to rebuild.

Fixed
- Claude Code's final cache usage is read as it is, a zero input placeholder
  kept over what was said before.
- File links open across shell cds and machines; a path is read in its root's
  style, so a POSIX project's files keep their slashes on Windows.
- A stopped turn no longer takes the next one with it; a proxy's
  authentication challenge is not mistaken for a logged-out account.
- What Claude Code abandons in a cut stream goes; unreadable rule files are
  skipped instead of failing all memory.
- OpenCode is told no session and no empty tool list; an upstream that refuses
  cache_control is asked again without it.
- Panes' tabs survive a restart, queued messages drag to a new place, and
  commands are the user's to run unless they say otherwise.

This update carries the current Claude Code.
