# 1.6.1

This fork develops the Windows version from now on: the macOS application is not built and not published any more. The Windows users who have it are not affected; it updates itself as before.

Changes
- The macOS application is not built and not published any more. The download page and the home page have no macOS part, and the links that pointed at it are gone (they led to a file that is not there).
- The release tool takes no macOS or disk image option any more, so the update manifest it writes names no macOS download.
- The macOS remote server is still offered (it runs on the SSH host, not on the desktop).
- The code's macOS branches stay: the app walks them when it runs on a Mac; they are just not published from here.

What this fork does differently from the upstream
- Every address the app gives out is this repository's own (the repository, the releases, the issues, the website); see Settings → About.
- No usage statistics are reported and no logs are uploaded: there is no server of its own, so there is nowhere to send them.
- The diagnostics say plainly that there is no server, rather than failing quietly.
- The channel build's activation page still points at the upstream (there is no replacement).
- The featured upstreams (ymeng / ifruit) are all gone: the list is empty and those pictures are no longer published with the site.
- notanthropic.com is not given the Anthropic key.
- A stash's path cannot leave its own folder.
- A very large version number does not crash the app.

Fixed
- See the 1.6.0 notes; there is nothing else fixed in this one.
