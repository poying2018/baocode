A core of our own

This release replaces Claude Code's core with one written in Dart, and makes it the default: no CLI to install, with sessions, CLAUDE.md, skills, subagents and MCP servers working as before. Windows can share your own browsers too, and agents can draw on an upstream's image models. Plus the composer, the side panel, scrolling and a batch of fixes.

New
- Our own core (Settings → General → Claude Code → Core): it runs on the upstreams of Settings → Models alone, with no Claude Code CLI on the machine. Sessions are still kept where and as the CLI keeps them, so you can switch between the two cores without losing a conversation. The built-in core uses an upstream's key; a Claude subscription's login belongs to the CLI alone, so switch back to the CLI to use one.
- No upstream, no session: the built-in core never falls back on the CLI's setup or the machine's environment variables. Without an upstream it says so, and offers to add one or to switch back to the CLI.
- Your browsers on Windows: the installer carries the bridge between them and the app (baocode-browser-host.exe), registers it for Chrome, Edge and Chromium, and takes it out at uninstall. The extension is unchanged.
- Drawing: agents generate images with an upstream's image models. With no default image model it asks which to use, and a picture made with another one offers Set as default. Pictures go to the path you asked for, else to images/date/ in the data folder.
- Polish in the composer keeps its tags, images and code, instead of flattening them to plain text.
- The side panel moves to the conversations' left, and back.
- New on the Stash page writes beside the cards, typed in at once, without another window.
- A mouse wheel glides lists, trees and editors instead of stepping through them.
- A turn under way shows its output tokens and speed live at its end.
- The status row muses on the step just done.

Improved
- A window closed while maximised or full screen leaves it first, with no black Space.
- What has no room in the sidebar or Stash gives way, instead of pushing its row off screen.
- A customize detail page's actions flush right, not halfway.
- The built-in core's tools, results and prompts are in its own words, with the CLI's behaviour.
- Events are logged off the drawing thread, not one disk write at a time: dragging a window and laying views out stays smooth.
- The emoji sheets of older versions are taken out when a new one is fetched, instead of 45 MB more each time.

Fixed
- Streamed text wrapped anew under a selection tells layout after it.
- Live speed is right when deltas come close together.
- Asked for a picture, an agent reaches for the image tool instead of writing about it.
- A message's editor opened as another closes gets all its room.
- On Windows, a diff card names its file and folder instead of showing the whole absolute path.
- And a batch of smaller problems.
