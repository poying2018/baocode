BaoCode Claude 1.10.5

同步上游至 1.9.6：Bot 群聊、重发消息可回滚文件、Windows 版 BaoCode Bash，
以及一批修复。

新功能
- Bot 群聊：把两个或更多 Bot 放进一个对话，它们轮流接话；每个 Bot 把听到
  和说过的记在自己的文件里，也可以真的忘掉。
- 重发较早的消息时可以一并还原之后几轮对文件的改动（设置 → 通用 →
  编辑过的消息）。
- BaoCode Bash：随应用提供的 bash，内置 rg、grep、sed、awk、find、jq，
  供 Windows 的终端和 agent 的命令使用。
- 一条消息最多可放 100 张图片。
- 项目的文件夹可以像工作区一样添加其他文件夹。
- Claude 订阅限额显示重置时间。
- 手机可以向电脑上传文件；离开时 agent 做了什么会推送给你；关于页显示
  本机设备 ID。
- 设置可以迁移到另一台电脑；新增 GitCode 账号。

修复
- Explorer 重启后托盘图标会自己回来。
- 表格单元格里的公式直接排版显示，不用点进去。
- 拖动窗口会把它提到前面；文件夹链接重新能打开。
- 归档的 agent 按文件夹分组。
