BaoCode Claude 1.9.0

功能版：把上游 1.8 以来的新东西整批带了过来——编辑器折行、全屏与缩放、
跨行查找、更好用的输入框，以及明显更低的 CPU 占用。你的东西一样都不会动。

新增
- 编辑器折行：在「设置 → 外观」里打开，或在编辑器里按 Alt+Z。
- 全屏：视图菜单，或按 F11。
- 缩放：Ctrl+= 和 Ctrl+- 每按一次把界面尺寸放大或缩小 2%，Ctrl+小键盘 0 复位。
  编辑器里的代码、侧边栏的文件和改动会跟着缩放。
- 编辑器里的查找和搜索都支持跨行匹配；带换行粘贴的文本会保留换行。搜索的
  「包含/排除的文件」和各项选项在重启后保留。
- 输入框的「润色」改成了「增强提示词」：辅助模型把你写的内容改写成更清楚、
  更具体的提示词，会读 AI 的上一条回复，所以「按第 2 个方案来」也能看懂。
  Ctrl+Z 可以撤回。
- 用 ChatGPT 账号跑 Codex 时，输入框下方会显示当前对话账号的剩余额度；
  点一下列出所有账号及其额度和重置时间。「额度重置后继续」也覆盖 ChatGPT 账号。
- agent 现在知道聊天会渲染数学公式、Mermaid 图、本地图片和折叠区块，会在
  合适的地方用上。Mermaid 图在回复流式输出时先显示占位，排版更好，也能像
  图片一样放大、右键操作。
- 可以在「打开语言服务器设置」里配置自己的语言服务器，保存即生效，不用重启。
- 侧边栏：项目可以一键全部折叠、全部展开；鼠标停在对话上会显示它用的模型。
- 对差异里的某一处改动「问 AI」：改动旁的按钮会把这处改动连同文件和行号
  放进聊天输入框，你看过再发。
- 「设置 → 外观」新增「原生窗口模糊」，在 Windows 11 上给窗口背景加系统
  模糊。默认关闭。
- 对话足够长时才出现小地图。
- 已经结束的后台任务可以清理，单个清或全部清。内置内核的 agent 干完活还有
  未勾选的待办时，会提醒模型更新待办列表。

修复
- 变基结束后，提交面板不再一直显示「变基中」，继续也不会失败了。
- 从主机列表里移除的 WSL 或 SSH 项目，再连同一台主机时不会再冒出来。第一次
  连接时没加载出来的远程文件夹，重试连上后会重新读取。
- WSL 里不会再误用 Windows 上装的 Claude Code；各处的 WSL 主机都按发行版
  名字显示。
- 子 agent 改的文件会随改随出现在审查里，项目外的改动可以查看和撤销。通过
  链接打开的项目里，文件不会再被当成项目外的文件。
- 换别的上游时，Claude Code 设置里的 availableModels 不会再把你的模型换成
  Claude 的。
- 发给你而不是写进文件的计划，现在会显示成计划卡片，可以直接开始。代码块
  在结束围栏处正确结束。
- 中文 Windows 上，失败的 MCP 命令输出不再乱码；用 HTTP 415 拒绝 BaoCode
  连接检查的 MCP 服务器，现在能正常通过。
- 输入法在选中文本上组字时，会替换选区。
- Windows 上，设置页上方的标题栏只显示窗口按钮；图片预览的关闭按钮不再压在
  窗口按钮下面。
- 在对话里拖动选择文本，即使中途被夺走焦点或加载更早的历史，选区也不会中断；
  打开的差异下方文本可以重新选中。
- Linux 上通知声音和桌面通知恢复正常。
- CPU 占用明显降低：窗口里没变化就不再重绘，加载动画统一每秒 30 帧，IDE 和
  侧边栏只在显示内容变化时重建。Git 和检查点改到后台运行。被忽略文件夹里的
  变化不再触发 Git 状态刷新，模型列表只计算一次。
- 持续卡顿会自动采样进日志，现在 Windows 和 Linux 也有，方便排查。
