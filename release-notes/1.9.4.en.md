BaoCode Claude 1.9.4

A fix release: six robustness fixes found by the new CI test run.

Fixed
- A terminal's shell-integration folder is private to your user again, whatever the umask says.
- A remote host's folder that is gone no longer hangs the file watcher.
- A code command installed before the rename is recognised as the app's own again: it is refreshed in place instead of showing as occupied.
- A Windows path is read right wherever the code runs, so builds and tests that name one on any platform see the same product.
- A project you took off the sidebar on purpose stays off when a removed SSH host is connected to again, even after a restart.
- A Git command the IDE runs is no longer refused when the remote server forwards it.
- An extension's old version is deleted cleanly even while Windows still holds one of its files.
- Clearing the browser's history succeeds even while Windows still holds one of its files.
