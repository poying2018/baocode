BaoCode Claude 1.8.0

This release brings the IDE's Git work all the way in: a commit panel that
takes part of a change, a log you can read and act on, blame in the
gutter, a three-way merge, and AI on hand for a change, a commit or a
conflict. A project inside a WSL distribution opens here too.

New
- Open a project inside a WSL distribution, beside the SSH hosts.
- Git, as JetBrains IDEs have it: local changes in a commit panel with
  changelists, commit options and message history, part of a file
  committed, Fixup, Update Project by merge or rebase, an interactive
  rebase, remote branches, Push, and a Stash tab.
- A Git log to work in: a branch tree, file, folder and line history,
  several commits selected at once, and diffs in the IDE's own way.
- Annotate with Git Blame, and the agent's changes marked in the gutter.
- Review with AI before committing, and ask AI about a change, a commit
  or a conflict; a conflict merged by AI.
- Local history of saved files, so a file's past can be looked at.
- A language server of your own, from Open Language Server Settings.
- Long lines wrap in the editors, one setting for all of them.
- Full Screen, from the View menu and F11.
- Collapse All and Expand All for the projects, a pinned project staying
  on top, and a conversation's hover saying the model it runs on.
- Edit a project's name and location, its conversations moving along.
- Clone a repository from the start page; manage remotes and tags.

Fixed
- An update could be taken as "already up to date" and never arrive. It
  arrives now.
- A stash written in and then emptied is a stash, not the draft the panel
  goes on with.
- A provider's models are let through the user's availableModels, in the
  batch test too.
- A subagent's edits outside the project, and a project opened through a
  link, are reviewed as they are.
- An input method composing over a selection replaces it.
- A code block ends at its closing fence.
- More than 256 open files no longer hang the processes started past it.
- Live output scrolls the way the wheel goes, and stays put when it ends.
- An update replaces the browser host the browser started again.
