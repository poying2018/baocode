Claude Code comes with BaoCode Claude: nothing to install, nothing to download

The app is called BaoCode Claude now, and it carries Claude Code itself. The
Windows installer brings the CLI along, so a machine with no Claude Code of
its own needs neither an install nor a download to get going: it is there,
ready, the first time a conversation starts.

Your own Claude Code is still the one that runs, if you have one, with your
sign-in, your settings and your CLAUDE.md. The copy the app carries is for
the machines that have none, and it is the floor rather than the ceiling:
one too old for what BaoCode asks of it is left for a newer one, which is
fetched then, as before.

That makes the installer bigger — about 100 MB instead of 16 — and it is the
only thing that changes about the download.

Nothing else moves. The program is installed over the one before it, in the
same folder; the data folder, the stashes, the keys in the keychain and the
update channel keep the names they have always had, so an upgrade finds
them where they are.

This release carries 1.6.0, 1.6.1 and 1.6.2 with it, so coming from 1.5.x
you get them too: the performance work of 1.6.0 (a long conversation that
streams and scrolls without falling behind, the Windows interface drawing
several times faster, Stash keeping in step with your projects' issues),
the macOS application no longer built or published here (this fork develops
the Windows version), and the tray icon of 1.6.2 really working — closing
the window to the tray again leaves an icon to click, and what the tray
did is written to `logs\tray.log`. Coming from 1.6.2, it is yours already
and only this release's own changes arrive.

The other program, BaoCode Codex, is not in this release: it is still being
built, and carries no Claude Code at all.

New
- Claude Code comes with the app: the Windows installer carries it, so there
  is nothing to install and nothing to download. Your own is used when you
  have one.
- The program is called BaoCode Claude now, and says so in its window, its
  title bar and its menus.

Improved
- The Claude Code the app carries is kept at the current build: the release
  checks it against the channel, and one too old for what BaoCode asks of
  it is left for a newer one, fetched when it is needed.
- The stashes, the keys in the keychain, the data folder and the update
  channel keep the names they have always had: an upgrade finds them where
  they are.
