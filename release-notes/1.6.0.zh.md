性能优化，Windows 上快了好几倍

这一版主要在提速和省内存：长对话里回复流式输出、滚动、拖动缩略图都更跟手，长时间运行占用的内存明显变少，Windows 上画面绘制快了好几倍。另外，Stash 现在能和项目在 GitHub / GitLab 上的 issue 双向同步；SSH 断线后会自动接回原来的会话，远程正在跑的东西一样不丢。

这个仓库的应用里，所有对外的地址都指向它自己：关于页的仓库、发布页与问题反馈，站点自己的文件（渠道列表、推荐上游），以及下载链接的许可名单。用到上游服务的两处不再用：使用统计不再上报（日志也不再上传），因为这个版本没有自己的服务器；渠道版的激活页仍指向上游，因为没有替代。

性能
- Windows 改用 Skia 绘制界面（和 macOS 一样），不再用 Flutter 新默认的 Impeller：实测对话界面每帧的绘制时间只有原来的几分之一，内存也只占原来的一半左右。
- 长对话流式输出更顺：回复里每个文件路径不再每次都去会话读过的所有文件里找。实测一个 92 轮的对话，每帧从 6.8 毫秒降到 4.5 毫秒，卡顿的帧从 18 帧降到 0。
- 很长的回复与思考过程把视野外的内容放开，只留高度，滚回来时再画出来；思考只画看得见的部分；横向滚动的代码、表格与公式存成图片。全选与复制仍拿到全部文字。
- 快速拖动缩略图或滚动条时不再同时构建视野外的内容，几帧后追上；滚走的回复滚回来不会重新解析。来回快速拖动，每帧从 12.9 毫秒降到 2.5 毫秒。
- 更省内存：Skia 的纹理缓存从 150～300 MB 收到 32 MB，解码后的图片收到 48 MB；macOS 上释放的大块内存还给系统，长思考流式输出时能还掉 180 MB 左右。
- 更轻的编辑器：同一种语言的文件共用一个语法高亮线程，它的模式只编译一次（TypeScript 的 334 个模式原本在三千多处各编译了一遍），行布局控制在 32 MB 左右。
- 计划模式下提示缓存会被读回：每一轮原本都把整段对话重写一遍，更慢也更费。
- 触控板在编辑器里滑动像列表一样；macOS 上列表到头不再回弹。

新功能
- Stash 与 issue 双向同步：在 GitHub / GitLab 仓库的项目里，打开的 issue 变成 stash，一行一条，带状态、标题、对话与 issue。双向保持同步：那边改了这里就取过来；这里改了确认后推过去；两边都改由你选；issue 关了它的 stash 就完成。默认所有打开的 issue；设置 → Stash → Issues as stashes 可以只留自己的，或关掉。
- Stash 动态：issue 有了新评论、关闭或重开、关联的 pull request 检查失败、要求修改、已合并 —— 各自标在那一行，与你有关的在侧栏 Stash 旁边计数。失败的 pull request 或要求修改的，点一下就在对话里改；已合并的会问这条 stash 是否算完。
- 一个 stash 可以发布成 issue：先展示要发出去的内容，指出本地的路径与密钥，本地图片一并上传。合并 stash 时可以把已合并的 issue 当作重复项关掉。
- 新的 markdown 编辑器：stash、侧栏的 markdown 预览与对话输入框都所见即所得地编辑，标记只显示在光标处。表格在单元格里编辑：增删行列、选中单元格、像表格软件一样复制粘贴；链接会弹出气泡，可打开、复制、编辑或删除。
- 自定义项：技能、规则、命令与子智能体在 markdown 编辑器里打开，按看到的样子编辑，或按源码编辑；front matter 显示为属性，按表单编辑。
- SSH 断线不丢东西：网络一抖，连接回到同一个会话，那边的终端、Claude Code 与语言服务器还在跑（断开后最多保留三小时），输出不丢也不重复；静默的网络在 30 秒内被发现。
- 到了用量上限还能继续：Claude 自家账号的模型选择器有 Continue After Limit Reset。开着的话，因上限停下的对话在重置后继续，即使电脑睡过了那一刻；应用关着时到期的重置，在打开时补上。
- 推荐用 Claude Code CLI：装了 Claude Code 的地方默认用它作内核；用内置内核的对话会在输入框上方建议改用，可以一键下载 CLI，或选暂不。
- 模型：子智能体与 Opus / Sonnet / Haiku 各档都能用另一个上游的模型；模型可以有自己的接入点（Anthropic、Chat Completions、Responses）；上游或模型一键复制；上游不再列出的模型一键清除。
- 缩略图：你的每条消息在它上面是一个清楚的标记。指针靠近就吸附过去，立刻显示那条消息与周围的回复；点一下就跳过去。
- 输入框：以 / 开头打任何词都会打开命令菜单；命令的标签悬停显示完整说明，Open details 在侧栏打开它所在的文件。@ 也能找到文件夹。输入框里的文件、文件夹与代码块可点开对应的内容。
- 智能体工作时，在空的输入框里按回车就把排队的第一条消息发出去；后台任务（子智能体也在其中）继续跑。
- 改动过的文件右键可以在浏览器里打开（HTML）、用系统默认程序或另一个编辑器打开、在文件管理器里显示，或复制它的路径。
- 侧栏的 markdown 预览接受拖入或粘贴的图片与文件，复制到文档旁边并加上链接；右键可以在文件管理器里显示链接的文件。

修复
- 切走再切回来的对话，停在上次离开的地方，那几步还开着。
- 在 Claude Code 里用 /rename 改过的名字，在列表里也是新的。
- Claude 设置里带 "viewMode": "verbose" 时，Stash 与输入框的润色、提交信息不再失败。
- 单个 ~（像 10-12~10-16 这样的范围）不再把中间的删除线划掉。
- markdown 预览铺满视野，宽表格不再被切掉；放大后，在里面拖动是在指针下面选中。
- 侧栏在左边且侧边栏隐藏时，它的标签不再挡住 macOS 的交通灯，侧边栏的开关也在；拖它的边缘时按显示出来的宽度跟随指针。
- 远程项目里的 Go to Definition 打开的是主机上正确的文件。
- Windows 上更新或卸载会先结束浏览器扩展的宿主进程，不再报 "DeleteFile failed; code 5"。
- 视图上方的图片加载时不再把下面的文字推着走；表格单元格里的链接也有气泡了。
- 用户自己的 CLAUDE_CODE_EFFORT_LEVEL 不再把思考强度钉死，选择器里选的就是发出去的。
- Windows 上不再把空闲线程立刻应答的 ping 误报成卡死。
- 浮层（菜单、弹出层、对话框）不再盖住 Windows 自己画的头部，那里的点击才有效。
- 智能体改过的文件不再自动在 IDE 里打开、跳到别的窗口。
