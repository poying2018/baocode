远程项目现在能用了

以前应用去上游的 dl.baocode.dev 下载远程主机的服务端，而那里没有我们的构建：服务端按源码定版本，只有做它的那台机器才有那一份，所以连远程主机一律 404。现在服务端的发布放在本仓库的 release 里，按版本号取——旧版本的应用也一直能下到它自己那份。

- 第一次连远程主机时，应用按 servers.json 从本仓库的 release 下载对应平台的服务端，校验大小和 SHA-256，之后照旧经 ssh 推送到主机。
- 随安装包带的是当前源码编出来的那一份（Linux x64 和 arm64），不用自己编。
- 从 1.3.0+15 直接升上来的话，也包括 1.3.0+16 的改动：内置内核会在待办列表长时间没被重写时提醒模型更新，面板不再一停几十分钟；这类给模型看的提醒也不再显示在工具卡片里。
