Linux，以及不必先开终端的 SSH

这一次把上游的 1.4 与 1.5 并进本仓库自己的发布线：应用现在可以在 Linux 上跑，
要连的服务器直接在应用里配好，不用先去终端折腾。自更新仍然从本仓库的 release
来——从 1.2.0 起就是这样。

新功能
- Linux：给 Ubuntu 等 Debian 系发行版的包，x64 与 arm64 都有，像 Mac 与 Windows 版那样自己更新。打开文件夹和文件用系统的对话框，右键菜单是系统的，粘贴文字、文件与图片也一样。
- Linux 会自己更新：像其它系统一样先下载并校验新版本，输一次密码装好，然后 BaoCode 自己重新打开。
- 添加 SSH 服务器：地址、端口、用户名和登录方式（密码、私钥，或像终端里那样交给 Automatic）都在应用里问，粘进来的 user@host:port 会替你拆开。~/.ssh 里的密钥会列出来供选，密码存在系统钥匙串。
- 跳板机：可以挑一台已保存的服务器连过去，每台各问各的密码。
- 第一次连上的服务器会自己记住它的主机密钥；密钥变了的会明说是哪一台，确认重装过之后可以移除旧指纹再连。
- 设置 → SSH Servers：应用里加的服务器和侧栏用过的主机都在这里，可以改、连、断、删。
- 每台服务器可选内核：Automatic（服务器上有 Claude Code CLI 就用它，没有就用内置内核）、内置内核，或 Claude Code CLI（没有就装上）。远程主机不再跟着本机的内核设置走。
- 第一次配置模型：还没有模型可跑时，欢迎页会说明「上游」是什么，点一下就能加一个，模型到位后会话自己就开始。
- 智能体可以用你自己的 Chrome（经 BaoCode 的扩展）：打开页面、点击、输入都用你已登录的状态，每一步都在侧栏里看得见。
- 给智能体的 DevTools 调试：源码与断点、元素、网络请求、站点数据、内存。
- 图片显示在对话里：工具生成的，以及消息自带的。
- 检查点只保留智能体改过的文件，不再是整个项目的快照；智能体的改动也可以在对话旁边逐段审阅。
- 长对话从末尾读起，往上滚到顶部时更早的轮次才加载；手机端也可以这样跟着读。
- Windows 安装包自带一份较新的 OpenSSH，系统那份太旧或没有时就用它。

改进
- IDE 里打字更顺：一次编辑只走它改过的那几行，输入法只拿到光标附近的几行，打字不再重绘整个 IDE。
- IDE 里切换对话标签更快：看过的对话留着，回到原处一次性显示。
- 侧栏的改动在 IDE 的 diff 编辑器里打开：窄的时候删除的代码排在正文旁，宽了就并排。
- 智能体工作时回复下方的时间、速度与 token 合成了一个开关（设置 → 通用）。
- 走 OpenCode 的网关时，一个会话的请求能命中它的提示缓存：更快，也更省。
- 长回复与思考过程会放开已经看远了的部分；各编辑器共用一套分词器，Skia 与图片缓存也保持得小。
- 模型菜单直接滚到正在用的那个模型，上游的模型在自己的设置页里按名字列出。

修复
- 预览里放大的图片会铺满窗口，不再被裁在它最初的大小里。
- 放大后，窗口标题栏的按钮一直到最右边都能点：尺寸和角点一样跟着界面的缩放走，按钮右缘不再变成拖动窗口。
- Windows 上装语言服务器改用 npm.cmd 自己的脚本（由 node 跑 npm-cli.js），PATH 上只有 PATHEXT 里的后缀才算数：nvm-windows 放在 npm.cmd 旁边的那个 Bash 脚本不会再被当 Win32 程序启动（那正是"不是有效的 Win32 应用"的来源）。由 .cmd 启动的服务端会连它的进程树一起结束，node 不会在 cmd.exe 被杀后继续跑。
- 一轮进行中换了另一个上游，接的是下一条消息，而不是还挂在原来那个上；智能体在后台做事时发的消息，会等当前这轮结束，或按设置并进去。
- 撞到用量上限停下的智能体，等额度重置后会继续；设了「重置后继续」的也会照做。
- 生成的图片、截图和读进来的图片，在对话切走再切回来后还在。
- 跳转到定义（F12）会把目标居中，哪怕它本来就在屏幕里。
- 鼠标滚轮像 Chrome 那样滚动对话，而且是平滑地滚动，每个刻度摊到几帧里。
- 电脑从睡眠醒来不再卡住：看门狗的时钟把睡眠时长算在外面。
- 主窗口回到上次关闭时的大小和位置，最大化过就还是最大化。
- NO_PROXY 的网段也传给了 Claude Code，其中的地址（Tailscale 的 100.64.0.0/10）会绕过代理，与 curl 的读法一致。
- 排队的消息一条一条来；现在手动发出的那条单独走。
- 更早的轮次在显示之前先加载，屏幕上的内容原地不动，转圈等到读完为止。
- Alt+Tab 回到窗口后，第一个按键就能输入，帧也继续画，不用先点一下。
- 原地移动的 stash（智能体在 Windows 上的写入）不用重启就能看到；符号链接在资源管理器里显示为它指向的东西。
