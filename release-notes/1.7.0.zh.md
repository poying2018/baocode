Claude Code 随 BaoCode Claude 一起来了：不用安装，也不用下载

这个程序现在叫 BaoCode Claude，并且自带 Claude Code。Windows 安装包里就带着它，
本机没有 Claude Code 的机器，第一次开始对话时它已经在那儿了：不用另外安装，也
不用等下载。

你若自己装了 Claude Code，跑的仍然是你那一份，用你的登录、你的设置和你的
CLAUDE.md。随包带的那一份是给没有的人用的；它是底线而不是上限：版本太旧、接
不住 BaoCode 传给它的选项时，就换成新的一份再跑，和以前一样。

代价是安装包变大了——约 100 MB，之前是 16 MB——下载的大小只变了这一处。

别的什么都没动。程序装在原来的那个程序里（同一目录），数据目录、stash、钥匙串里
的密钥、更新通道，名字都还是原来的名字，升级时它们就在原地。

另一个程序 BaoCode Codex 以它自己的名字一起发布，它完全不带 Claude Code。

新功能
- Claude Code 随应用一起提供：Windows 安装包就带着它，不用安装，不用下载；你
  自己有的话，仍然用你那份。
- 程序现在叫 BaoCode Claude，窗口、标题栏和菜单里都是这个名字。

改进
- 随包带的 Claude Code 保持在当前版本：发版时会与发布渠道核对，接不住 BaoCode
  传给它的选项的旧版本会被换掉，需要时再取一份新的。
- stash、钥匙串里的密钥、数据目录和更新通道，都还是原来的名字：升级时它们就在
  原地。
