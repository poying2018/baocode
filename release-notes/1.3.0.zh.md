自己的内核

这一版把 Claude Code 的内核换成了 BaoCode 自己写的 Dart 实现，默认就用它：不再依赖本机装的 CLI，会话、CLAUDE.md、技能、子智能体和 MCP 服务器照旧。Windows 上也能共享本机浏览器了，agent 还能用上游的图片模型画图。此外是输入框、侧边栏、滚动和一批修复。

新功能
- 自己的内核（设置 → 通用 → Claude Code → 内核）：直接在 设置 → 模型 里配置的上游上跑，不需要本机装 Claude Code CLI。会话仍按 CLI 的位置和格式保存，所以两种内核可以来回切换，对话不丢。内置内核用上游的密钥；Claude 订阅的登录只属于 CLI，靠订阅的话把内核切回 CLI 即可。
- 没有上游就不开会话：内置内核只认 设置 → 模型 里的上游，不会悄悄退回本机 CLI 的配置或环境变量。没有上游时会直接说明，并给出去加一个、或切回 CLI 的入口。
- Windows 上共享本机浏览器：安装包里带上浏览器与应用之间的桥（baocode-browser-host.exe），安装时登记 Chrome、Edge 和 Chromium，卸载时清除。扩展不用换。
- 画图：agent 可以用上游的图片模型生成图片。没设默认图片模型时会问用哪个，用非默认模型画完之后可以一键设为默认。图片存在你指定的路径，没指定就放在数据目录的 images/日期 下。
- 输入框里的润色：标签、图片和代码都会保留，不再被当成纯文本冲掉。
- 侧边栏可以移到对话左侧，也可以移回去。
- Stash 页面的「新建」就地输入，不必再另开一个窗口。
- 鼠标滚轮滚动列表、树和编辑器时有缓动，不再一格一格跳。
- 对话进行中，末尾会实时显示输出 token 数和速度。
- 状态行会回顾刚完成的步骤。

改进
- 窗口在最大化或全屏时关闭，会先退出全屏，不再黑屏一下。
- 侧边栏和 Stash 里放不下的东西会自己让位，不再把整行挤出屏幕。
- 自定义详情页的按钮靠右对齐，不再停在半中间。
- 内置内核的工具说明、参数、结果和提示词都用自己的措辞，行为和 CLI 一致。
- 事件日志改为后台写入，不再在绘制线程上逐行等磁盘：拖动窗口、切换视图时更顺。
- 旧版本的表情图缓存会在下载新版时删掉，不再一直占着几十 MB。

修复
- 流式文字在选区下方重新换行时会正确通知布局。
- 增量的间隔很短时，实时速度也能正确显示。
- 被要求画一张图时，agent 会去用画图工具，而不是只写文字。
- 一个编辑框在另一个关闭时打开，能拿到全部空间。
- Windows 上改动卡片显示文件名和所在目录，不再显示整条绝对路径。
- 还修了一批小问题。
